This is an Expo and React Native mobile app. Favor mobile-first patterns, performance, and iOS and Android compatibility.

## Expo and React Native

Before changing Expo, EAS, or React Native APIs, check the Expo version in `package.json` and use its matching documentation at `https://docs.expo.dev/versions/v<major>.0.0/`. For other Expo questions, consult `https://docs.expo.dev/llms.txt` and follow its links to the relevant docs.

Use Expo Router for navigation. Route files belong in `src/app/`; keep reusable components, hooks, and utilities elsewhere. If `ios/` and `android/` are absent, they are generated by Continuous Native Generation. Configure native behavior in `app.json` or config plugins rather than creating those directories by hand.

Libraries with native code need a development build; Expo Go only includes its bundled native modules.

## Project decisions

Use `@/…` absolute paths for all client-side local imports and asset `require` calls (`@/assets/…` for assets). Keep package imports as package names.

Follow [docs/tech-choices.md](docs/tech-choices.md) for technology and implementation choices.

Issues and specs live in `.scratch/`; see [docs/agents/issue-tracker.md](docs/agents/issue-tracker.md). Use the triage labels in [docs/agents/triage-labels.md](docs/agents/triage-labels.md), and follow the single-context layout in [docs/agents/domain.md](docs/agents/domain.md).

## Checks

Run `pnpm dlx prettier --write --ignore-unknown <files>` on every modified or created file before declaring a task complete.

Run `pnpm exec expo lint` and `pnpm exec tsc --noEmit` before declaring a task complete.
